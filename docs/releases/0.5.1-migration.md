Actualizar `@raulbellosom/atlas-web-builder` a `0.5.1`, regenerar el lockfile del consumidor y reconstruir. JavaScript y `@raulbellosom/atlas-web-builder/styles` deben proceder de 0.5.1; actualizar únicamente el CSS no incluye la compensación del zoom.

No hay migraciones de documentos, cambios de dependencias, exports, Page schema 1, Website v2 ni capacidades v1. El renderer público conserva su comportamiento. Mantener autorización, sandbox, CSP y restricciones del host.

La corrección está verificada en Chromium/WebKit automatizados. No está certificada en iPhone/Safari ni Android físicos; continúa pendiente la aceptación del bloqueo táctil original comunicado en iPhone. No se afirma que esta corrección visual resuelva ese incidente.

Las correcciones de integración del Hub y del viewport público histórico del ERP están en sus propios repositorios y no se incluyen en este paquete. La publicación npm no actualiza ni despliega esos consumidores.
