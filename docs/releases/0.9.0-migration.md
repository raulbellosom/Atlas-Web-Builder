# Atlas Web Builder 0.9.0

La resolución responsive usa el ancho del contenedor `atlas-page`, independiente
del viewport y del zoom del editor. Desktop hereda a tablet y mobile; los overrides
planos usan el convenio `tabletCampo` y `mobileCampo`. Cero, false y una cadena
vacía válida conservan su significado. Page continúa en schema 1.

El Inspector permite copiar y restablecer overrides con undo/redo. Box conserva
sus defaults móviles históricos; `mobileColumnsInherit` expresa una restauración
explícita de la herencia. Los hosts con catálogos restringidos deben registrar los
campos nuevos antes de habilitar estos controles. No cambiar los catálogos ni los
digests asociados a documentos anteriores.

`containerPreset` admite full, xl (1280), 2xl (1536) y custom. `fullBleed` permite
fondo exterior y contenido limitado/centrado. Fondos, tipografía, espaciados,
dimensiones, flex/grid y ajuste de imagen tienen overrides por dispositivo.

`visibility: hidden` conserva espacio, como antes. `collapsed` utiliza display
none; `visible` restablece la visibilidad y el display natural del elemento.
Los hosts deben comprobar la navegación asistida con su contenido real.

La nueva exportación `inspectOverflowDetails` devuelve candidatos y medidas;
la propiedad responsable es una estimación. No modifica documentos. La reparación
del Inspector necesita una aplicación explícita y puede deshacerse.

Validación de fuente: 250 pruebas, lint y build. El comando
`node scripts/verify-responsive-release.mjs <tarball>` instala el paquete en
consumidores npm independientes React 18.3.1 y 19.3.0; verifica fuentes del
sourcemap, exports ESM/CJS, datos históricos, roundtrip, SSR e hidratación en
Chromium/WebKit con canvas 390/820/1440 dentro de viewport 1920.

La publicación de esta biblioteca no adopta ni despliega ERP/Developer Hub.
Mantener el pin anterior 0.8.2 y sus artefactos como restauración. Un rollback del
host no debe reserializar ni eliminar campos nuevos de documentos existentes.
El cambio del dist-tag de npm tampoco actualiza dependencias fijadas a una versión.
No se certifican sitios concretos, hardware móvil físico ni integraciones del host
mediante las pruebas aisladas de este paquete.
